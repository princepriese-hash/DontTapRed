# Don't Tap Red

Stage 1 playable Godot 4.x prototype for Android portrait. Open the project in Godot 4.7.x and run the main scene. Tap safe objects, avoid red octagons, and survive as levels accelerate.

Headless validation:

```text
Godot_v4.7.2-stable_win64.exe --headless --path . --quit
Godot_v4.7.2-stable_win64.exe --headless --path . -s tests/run_tests.gd
```

The installer executables in this workspace are local tooling and are intentionally not part of the Git repository.
