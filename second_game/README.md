# Don't Tap Red — Second Prototype

This is a separate Godot 4.3+ prototype project implementing the requested minimal loop:

- portrait mobile viewport;
- modular `SecondGameManager`, `SecondSpawnManager`, `FallingShape`, and HUD scripts;
- green safe squares and red danger squares falling at random horizontal positions;
- tap green to destroy it and add one point;
- tap red to enter Game Over;
- Start/Retry screen.

Run `res://scenes/main.tscn` in Godot and use touch or the mouse emulator to verify interactions.
